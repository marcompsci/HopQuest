# HopQuest (v0.9)

Kid-safe educational hop & drive game for iPhone/iPad. SwiftUI + SpriteKit + AVFoundation, no dependencies. All art and audio are original and generated by the scripts in `ArtSource/`.

## Run it
1. Unzip, then double-click **HopQuest.swiftpm** (opens in Xcode 15+; also works in Swift Playgrounds on iPad/Mac).
2. Pick an iPhone simulator (e.g. iPhone 16) and press **Run** (⌘R).
3. To run on your own phone, set your Team under the app's Signing settings.

Want a regular .xcodeproj instead? Create a new iOS App project in Xcode, delete its ContentView/App files, and drag the `App`, `Models`, `Views`, and `Scenes` folders in.

## Layout
- `App/` — entry point and screen routing (map → level → balloon → map)
- `Models/` — player profile & local save, characters, chapters, Brain Gate questions
- `Scenes/` — SpriteKit: `HopScene` (crossy-road levels), `DriveScene` (Driving School), `SpriteFactory` (all code-drawn art)
- `Views/` — SwiftUI: onboarding, character picker, world map, balloon flight, Robot Lab, quiz card, parent gate/settings

## Tuning
- Level length / difficulty / gate frequency: `Models/Chapters.swift`
- Questions: `Models/Questions.swift`
- Characters: `Models/Characters.swift` (keep them original — see GAME_DESIGN.md §2)

See **GAME_DESIGN.md** for the full design, parent research, App Store Kids checklist, and roadmap.
